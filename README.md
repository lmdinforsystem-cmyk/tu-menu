#  TuMenú

TuMenú es una aplicación web que permite descubrir recetas, aprovechar los ingredientes que tenemos en casa y guardar nuestras recetas favoritas.

## Funcionalidades

- **Mi nevera:** permite buscar recetas introduciendo un ingrediente.
- **Descubre recetas:** permite explorar diferentes propuestas de cocina.
- **Mis favoritos:** permite guardar y eliminar recetas favoritas.
- **Almacenamiento local:** los favoritos se guardan en el navegador mediante LocalStorage.

##  Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Programación Orientada a Objetos (POO)
- API TheMealDB
- LocalStorage

##  Cómo ejecutar el proyecto

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el archivo `index.html` utilizando la extensión Live Server.
4. Navegar por las diferentes secciones de TuMenú.

##  Objetivo del proyecto

Este proyecto se ha desarrollado como parte de un trabajo de aprendizaje de JavaScript, con el objetivo de practicar la manipulación del DOM, el uso de clases, el consumo de APIs y el almacenamiento de datos en el navegador.
